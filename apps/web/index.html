Local Safety & Reliability Guardrails

Deterministic AST analysis and security checks executed locally on every AI generation.

Deterministic AST Syntax Validation

Every generated Python module is parsed via Python's native ast.parse() before writing to disk. Catches unclosed parentheses, indentation errors, or unescaped symbols, preventing broken code deployment.

Zero-Hardcoded Secrets Scanner

Regex-powered credential scanner inspects all target files for leaked AWS tokens, private keys, database passwords, and API keys. Enforces safe environment variables via .env.example.

Read-Only SQL Safety Linter

Parsed with sqlparse to block destructive DDL (e.g. DROP DATABASE, unconditional DROP TABLE). Guarantees that original legacy databases are strictly read-only and never altered.

Self-Healing Equivalence Verification

Agent 4 synthesizes Pytest (Python) or JUnit 5 (Spring Boot) integration test suites. Tests run in an isolated subprocess; if failures occur, tracebacks are fed back into Agent 3 for automated self-healing.
